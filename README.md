# Sharia Law — Interactive Educational Resource

An interactive educational resource on Islamic Sharia law covering Maqasid al-Sharia, legal sources, schools of thought, and contemporary applications.

## Features

- ⚖️ **11 Content Tabs** — Overview, Principles, Sources, Schools, Quran, Hadith, Maxims, Application, Quiz, Glossary, Resources
- 🌙 **Dark/Light Theme** — Toggle with localStorage persistence
- 🔍 **Full-Text Search** — Search across all content with highlighting
- 📝 **Knowledge Quiz** — 8 questions testing Sharia fundamentals
- 📚 **24-Term Glossary** — Expandable definitions of key Islamic legal terms
- 📊 **Comparison Table** — How 4 madhhabs differ on common issues
- 📱 **PWA Support** — Works offline after first visit

## Topics Covered

- **Maqasid al-Sharia** — 5 higher objectives (Faith, Life, Intellect, Lineage, Property)
- **Primary Sources** — Quran, Sunnah, Ijma, Qiyas
- **Schools of Thought** — Hanafi, Maliki, Shafi'i, Hanbali, Ja'fari
- **Quranic Foundations** — Key verses establishing Islamic law
- **Legal Maxims** — 5 core qawa'id fiqhiyyah
- **Contemporary Applications** — Finance, family law, medical ethics, technology

## Quick Start

```bash
cd Sharia-Law
python3 -m http.server 8080
# Open http://localhost:8080
```

## Tech

Single-file HTML/CSS/JS application. No build step, no dependencies.
